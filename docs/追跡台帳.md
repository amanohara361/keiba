# 追跡台帳（観察中の数字と、その判定の条件）

2026-11-17 作成（`docs/調査/改善点_2026-11-17.md` の8）。決定ログ・`review.py`・スケジュール済みタスクに散らばっている
「観察中・目安に届いたら判断する」ものを1か所に並べる。**判定の条件は始める前に書き、後から動かさない。**
条件を変えるときは、この表と決定ログの両方に、変えた日と理由を書く。

## 判定のルール（全追跡に共通）

1. **目安に届いたら「検討どき」になるだけで、承認にはまだかけない。** 後の期間（目安に届いた日より後）で同じ向きが出てから承認にかける
   （運用ルール 2026-10-16。これを全追跡に徹底する）。
2. **z≥2 の目安は、同時に何本も走っていると偶然届く。** z を物差しにする追跡がいま6本ほどあり、どれも本当は差が無くても、
   どれか1本が偶然 z≥2 に届く確率は約13%（1本あたり約2.3%）。1のルールで後の期間の再現を必ず通すことで、この偶然を落とす。
3. 区切り・しきい値を、届いたかどうかを見ながら動かさない。動かした場合は、そこから数え直す（since を進める）。
