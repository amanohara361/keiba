# 地方の1番人気：確定単勝2倍未満と2倍以上で成績は違うか（2026-10-07）

**この文書は調査の記録で、予想の基準ではない。** 予想メソッドに反映するかは別に決める。

## 疑問
地方は1番人気がよく勝ち、1倍台も多い。一方で、2倍以上の1番人気は馬券圏内から外れたり、
1着を取り逃したりする印象がある（ユーザーの印象。客観的な測定は無かった）。

## 結論
- **勝率の差は有意**。2倍未満 56.5%、2倍以上 31.8%（p < 10⁻¹⁰⁰）。全14場で同じ向きで、全体を前半（2〜5月）と後半（6〜9月）に分けても再現する。
- ただし**その差はオッズがすでに織り込んでいる**。2倍以上の実勝率 31.8% は市場想定 32.3%（0.8 ÷ オッズ）とほぼ同じで、
  2.0〜2.5／2.5〜3.0／3倍以上と刻んでも想定との差は有意でない（p = 0.33〜0.77）。単勝回収率も 81.5% と 79.4% で差なし（p = 0.32）。
  「2倍以上の1番人気は、オッズの割に弱い」わけではない。
- **複勝だけは差がある**。8頭以上のレースで複勝回収率 91.4% と 84.5%（p ≈ 10⁻⁸）。2倍以上の1番人気の複勝は割に合わない。
  2倍未満の側は元返し（100円未満でも100円を返す特例）が押し上げている可能性があり、切り分けていない。
- **場の違い**：2倍以上は場による差なし（p ≈ 0.75）。2倍未満は境界的（p ≈ 0.04）で、
  大井・水沢・盛岡が想定より勝ち、浦和（47.7%／想定54.4%）・笠松が想定より負け。14場を同時に比べた結果なので**仮説どまり**。

## 予想への示唆（未承認・材料のみ）
1. 2倍以上の1番人気を1着固定にすると、3回に2回は外れる。◎は「1番人気か」ではなく、単勝オッズ（＝市場勝率）で考える。
   いまの `bet_builder` は単勝オッズから市場勝率を出しているので、この考え方とはすでに合っている。
2. 2倍以上の1番人気の複勝は、買い目の候補として不利。
3. 浦和の1倍台は信用しにくい、という仮説は 2026年10月以降の分で再集計して確かめる。

## データと方法
- keiba.go.jp の月次CSV。確定オッズ（OddsDataDownload）は**2026年2月より前が公式から消えていた**ため、期間は 2026-02-02〜09-30 の8か月。
- 1番人気が1頭に決まり、その馬が完走した、完走5頭以上のレース 9,083鞍（ばんえい除く。ばんえいも同じ傾向で、2倍未満 54.9%・2倍以上 29.2%）。
- 確定オッズであることの検算：勝ち馬の払戻÷100 と確定オッズが 10,198鞍中 10,180鞍で一致。
- 1レース1行に縮めた表を `data/nar_fav/YYYYMM.csv` に保存している（公式からオッズが消えても再集計できるように）。

再集計：

```
python nar_fav_odds.py fetch 202610      # 月が終わったら1か月分を足す
python nar_fav_odds.py report            # 全期間
python nar_fav_odds.py report 202610 202612
```

## 確認が必要な点
- 期間が8か月で、季節の偏りは残る。
- 市場想定勝率は払戻率を一律80%として計算した。主催者ごとの実際の払戻率は確かめていない。
- 地方の1番人気の勝率が中央より高い、という前提そのものは、この調査では比べていない（中央のデータは入れていない）。
