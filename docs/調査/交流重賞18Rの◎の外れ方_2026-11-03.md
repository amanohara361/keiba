  - 10-06 より前は、◎を1番人気から外したレースで1番人気がよく勝った（◎の付け方で市場に負けた）。この期間はカードに中央所属馬の中央の近走が入っていなかった（2026-10-06 修正のバグ。9/3〜10/1の5レース）。
  - 10-06 以降は、◎の8割が市場の1番人気と同じ馬で、1番人気自体も見込みの半分しか勝っていない。**◎と市場が一緒に外れた**のが中心で、比べ方が悪いとまでは言えない。

- ◎が1番人気だった11レースで2勝以下になる確率は、市場どおりに勝つとしても約11%ある（偶然でも起きうる外れ方）。

## 外れ方の型
- **A：市場の1番人気に◎を打ち、市場と一緒に負けた**（11R・2勝・見込み4.42）。負けた9Rのうち7Rは、◎の弱点（休み明け・初めての条件・ハナ争い）を note に書いていた。主観勝率は11R中9Rで市場より低く、◎を強く見すぎてはいない。
- **B：中央馬を見ずに地方馬へ◎**（2R：8/13 北海道スプリントC・9/3 サマーチャンピオン。0勝）。どちらも1番人気が勝った。9/3 は中央3頭の近走が0件で無印にした。8/13 は note に「中央成績未確認」。
- **C：中央馬どうしで市場と順序を逆にした**（5R：9/1 不来方賞・9/23 オーバルS・10/1 マリーンC・11/3 JBCレディス・11/3 JBCクラシック。0勝・見込み1.14）。
  根拠は、直接対決や距離の重視（9/1）、減点の機械的な適用（9/23「牝馬限定から混合へ −5」をJpnIII勝ち馬に）、単騎逃げの読み（10/1）、格の重視（11/3L）、斤量差の重視（11/3C）。
  9/1・9/23・11/3C は1番人気が勝ち、その馬の印は○か△。9/23・10/1 はデータ欠落も重なる。
- 「地方の実績を過大評価して中央馬より上に置いた」型は、B以外には無かった。

## 市場が見ていて、朝が見ていなかったもの（推定）
- 近走が取れていない中央馬の力（8/13・9/3・9/22・10/1）。
- 中央の重賞を勝った馬に、減点ルール（性別替わり・距離延長など）を機械的に当てること（9/23・9/1）。

- ③は確定オッズで数えた値。◎を1番人気に寄せると、◎の勝率は定義上ほぼ市場と同じになり、**市場を上回る余地が無くなる**（控除の分だけ負ける）。買う理由を作る案ではなく、外れを減らすだけの案。
  10-06 以降に限ると、変わるのは2Rで、増えるのは1勝だけ。
