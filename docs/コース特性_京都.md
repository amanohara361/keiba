# 京都競馬場のコース特性と距離別の狙い目

2026-10-06 追加。ユーザーが共有した解説動画の要約（[mm:ss] は動画内の時刻）。
**予想メソッドの原本ではなく参照資料**。印の根拠に使うときは note に「コース特性（京都）」と書き、
予想メソッドの「理由を説明できるデータにのみ従う」（コース形状・坂の有無など）の範囲で使う。
回収率・複勝率などの数字は検証していない。外れた・当たったの記録が貯まったら `検証ノート.md` で見直す。

阪神（直線に急坂）との対比が軸なので、**前走阪神→今回京都**の馬を見るときにとくに使う。

## 1. 全体の特徴

- **淀の坂** [02:04]：向正面から登り、3コーナーで頂上、4コーナーにかけて下る。
  高低差は外回り約4.3m／内回り約3.1m。
  「登りでペースが落ち、下りで勢いがついて平坦な直線に入る」ため、ペース配分とロングスパート性能が効く。
- **最後の直線は平坦** [03:21]：阪神（直線に急坂）の坂で止まって負けた馬が、京都で粘り込む巻き返しが最大の狙い目。

## 2. 芝コース

| 距離・コース | 主な特徴 | 狙い目 |
|---|---|---|
| 芝1200m（内）[04:33] | 序盤が登り坂でハイペースになりにくい | 内枠（1〜2枠）で4角3番手以内の逃げ・先行馬 |
| 芝1400m（外）[05:50] | 序盤が緩みやすく、直線が長い（404m） | 1600m以上からの距離短縮（初1400m） |
| 芝1600m（外）[06:51] | 1番人気の信頼度が低い／下りで加速して差しが決まる | 前走マイル組で、内をロスなく突く（イン差し）馬 |
| 芝1800m（外）[08:17] | 最初のコーナーまで約900mあり、先頭争いで前崩れしやすい | 前走上がり3F 3位以内の差し馬 |
| 芝2000m（内）[09:02] | スタート直後から先頭争い→中盤は下りで緩まない | 内枠で1コーナーを5番手以内で回れる先行馬 |
| 芝2200m（外）[09:38] | 3〜4角の下りから息の長い末脚が要る持続力勝負 | 前走2400m以上からの距離短縮＆上がり3位以内 |
| 芝2400m（外）[10:39] | 直線の持続力勝負。逃げは苦戦、後方一気も届ききらない | 4角中団以内＆前走上がり3位以内 |
| 芝3000m [11:16] | スタート直後が坂＆コーナー6回で距離ロスが大きい | 内枠で折り合いに不安のないスタミナ血統 |
| 芝3200m（外）[12:25] | 淀の坂を2回越える／ロングスパート性能が重視される | 内枠で4角8番手以内につけられるスタミナ血統 |

※ 動画の要約では芝3000mを「内」としていたが、菊花賞の芝3000mは**外回り**で、坂も2回越える。ここは外回りとして扱う。

## 3. ダートコース

| 距離 | 主な特徴 | 狙い目 |
|---|---|---|
| ダ1200m [14:42] | 阪神ダ1200mと違い、下り坂の勢いのまま平坦な直線に入るので前が止まりにくい | 4コーナーを3番手以内で回れる先行馬 |
| ダ1400m [15:25] | 芝スタートで外枠有利（芝部分を長く走れる＋砂を被りにくい） | 阪神ダ1400mの坂で粘れなかった外枠の馬 |
| ダ1800m [16:17] | スタートから1コーナーまでが極端に短く、逃げ・先行が圧倒的有利（逃げ馬の複勝率が高い） | 4コーナーを3番手以内で回れる先行馬 |
| ダ1900m [16:43] | 1800mから100m延びるだけで、差し・追い込みがよく届く展開に変わる | 京都ダ1800mで差し届かなかった差し・追い込み馬 |

## 4. 馬券の組み立ての軸

1. 淀の坂の下りを使ったロングスパート適性を見る。
2. 「阪神の急坂で敗れた馬」の京都での巻き返しを狙う（前走阪神の着順だけで切らない）。
3. コース形態（内回り・外回り、スタート位置）による有利・不利を押さえる。

## 使い方の注意

- 当日のトラックバイアス（`data/bias/`）と食い違ったら**当日の実測を優先**する。この表は平均的な傾向でしかない。
- 「1コーナーまで短い＝先行有利」は、予想メソッド第4ステップの逃げ候補一覧（ハナを主張する馬の頭数）とセットで使う。逃げ候補が多ければ前崩れもありうる。
